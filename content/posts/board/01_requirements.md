_기능별 커밋을 위한 요구사항 명세서_ 

<br>

## 1. Users

#### 회원가입 및 인증

* [ ] **회원가입**
    * [ ] 이메일, 비밀번호, 닉네임을 입력받아 가입한다.
    * [ ] 이메일과 닉네임은 중복될 수 없다 (`UNIQUE` 제약조건).
    * [ ] 비밀번호는 암호화하여 저장해야 한다 (BCrypt 등).
    * [ ] 기본 권한(`role`)은 'USER'로 설정된다.
* [ ] **로그인**
    * [ ] 이메일과 비밀번호로 인증한다.
    * [ ] 인증 성공 시 Access Token(JWT)을 발급한다.
* [ ] **내 정보 조회**
    * [ ] 로그인한 사용자는 자신의 프로필 정보(이메일, 닉네임, 가입일 등)를 확인할 수 있다.

<br>

#### 회원 관리 (Optional/Admin)

* [ ] **회원 탈퇴**
    * [ ] 회원이 탈퇴하면 연관된 데이터(작성 글, 댓글 등) 처리를 결정한다.
    * [ ] DB `CASCADE` 설정
* [ ] **팔로우/언팔로우**
    * [ ] 다른 사용자를 팔로우(`follows`) 할 수 있다.
    * [ ] 이미 팔로우한 사용자를 다시 클릭하면 언팔로우 된다 (Toggle).
    * [ ] 자기 자신을 팔로우할 수 없다.

<br>
<br>
<br>

## 2. Categories

#### 게시판 카테고리

* [ ] **카테고리 목록 조회**
    * [ ] 게시글 작성 및 조회 시 사용할 전체 카테고리 목록을 조회한다.
* [ ] **카테고리 즐겨찾기** (`category_favorites`)
    * [ ] 로그인한 사용자는 자주 가는 카테고리를 즐겨찾기 할 수 있다.
    * [ ] 내 즐겨찾기 카테고리 목록만 따로 조회할 수 있다.
* [ ] **카테고리 관리 (Admin Only)**
    * [ ] (초기 데이터) 관리자는 카테고리를 생성/수정/삭제할 수 있다.
    * [ ] 카테고리 이름은 중복될 수 없다.

<br>
<br>
<br>

## 3. Posts

#### 게시글 작성/수정/삭제

* [ ] **게시글 작성**
    * [ ] 로그인한 사용자만 작성 가능하다.
    * [ ] 제목, 내용, 카테고리는 필수 입력값이다.
* [ ] **게시글 수정**
    * [ ] 작성자 본인만 수정 가능하다.
    * [ ] 제목, 내용, 카테고리를 수정할 수 있다.
    * [ ] 수정 시 `updated_at` 시간이 갱신되어야 한다.
* [ ] **게시글 삭제**
    * [ ] 작성자 본인만 삭제 가능하다.
    * [ ] 삭제 시 달려있는 댓글, 좋아요, 스크랩 정보도 함께 삭제된다 (`CASCADE`).

<br>

#### 게시글 조회

* [ ] **게시글 목록 조회 (Paging)**
    * [ ] 모든 사용자는 게시글 목록을 볼 수 있다.
    * [ ] 페이지네이션(Page, Size)이 적용되어야 한다.
    * [ ] 최신순(`created_at DESC`)으로 정렬한다.
    * [ ] (선택) 특정 카테고리의 글만 필터링해서 볼 수 있다.
* [ ] **게시글 상세 조회**
    * [ ] 게시글의 상세 내용(제목, 내용, 작성자, 작성일 등)을 조회한다.
    * [ ] 상세 조회 시 **조회수(`view_count`)가 1 증가**해야 한다.
    * [ ] (선택) 자신이 누른 좋아요/스크랩 여부를 함께 반환한다.

<br>

#### 게시글 상호작용

* [ ] **좋아요 (Likes)**
    * [ ] 로그인한 사용자는 게시글에 좋아요를 누를 수 있다.
    * [ ] 중복 좋아요는 불가능하며, 다시 누르면 취소된다 (Toggle).
* [ ] **스크랩 (Favorites)**
    * [ ] 로그인한 사용자는 게시글을 스크랩(`post_favorites`) 보관함에 저장할 수 있다.
    * [ ] 중복 스크랩은 불가능하며, 다시 누르면 취소된다.

<br>
<br>
<br>

## 4. Comments

* [ ] **댓글 작성**
    * [ ] 로그인한 사용자만 작성 가능하다.
    * [ ] 내용은 필수 입력값이다.
* [ ] **댓글 목록 조회**
    * [ ] 특정 게시글에 달린 댓글 목록을 조회한다.
    * [ ] 생성일 순(`ASC` or `DESC`)으로 정렬한다.
* [ ] **댓글 삭제**
    * [ ] 작성자 본인 혹은 게시글 작성자(선택 사항)가 삭제할 수 있다.
