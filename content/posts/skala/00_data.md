## EDA: Exploratory Data Analysis
- 탐구적 자료분석 -> 자료를 탐구함으로써 시작하는 통계적 분석 형태
- 데이터를 우선 살펴보고 인사이트를 도출한다
- 분석모형은 최대한 EDA를 통해 도출된 특징을 기반으로 함
- 데이터 특징을 찾지 못했다면 분석모형과 분석결과는 신뢰하기 어렵

## 기초 통계
기초통계량 사용하는 요소들
- 중심화
    - 평균, 이동평균, 중앙값, 최빈값
- 퍼짐
    - 표준편차, 변이계수, 사분위수, 사분위수 범위, IQR, 최대-최소-범위
- 분포/대칭
    - 왜도, 첨도

1. 중심화
- 평균
- 중앙값
- moving average: 일정한 구간의 데이터를 평균 내어 전반적인 추세를 파악하는데 유용
    - 장점
        - 데이터 변동을 부드럽게 볼 수 있음
        - 추세 파악에 유리
    - 주의사항
        - 지연(Lag) 발생: 실제 변화보다 늦게 반응함
        - 이상치에 민감할 수 있음
        - 적절한 윈도우 선택해야: 너무 크면 흐름이 무뎌지고, 너무 작으면 잡음이 반응함.
    - 일목균형표
        - 전환선: 단기추세선 (09일간의 최고가 + 최저가)/2
        - 기준선: 중기추세선 (26일간의 최고가 + 최저가)/ 2
        - 선행스팬1: (전환선 + 기준선) / 2
            - 과거의 단기/중기 가격 분포 중심을 현재 시점에 겹쳐놓은 기준선
        - 선행스팬2: (s2기간 최고가 + 최저가) / 2
            - Range-based midpoint 가격이 움직일 수 있는 공간의 정중앙
        - 후행스팬
2. 퍼짐
- 표준편차
    - 편차의 제곱평균 -> 해석가능한 수치로 바뀌며, 단위가 바뀌지 않음
- 분산
    - 편차의 제곱. 단, 수치가 크고 단위가 바뀐다.
- 사분위수
    - 사분위수 범위: ~25, ~50, ~75, ~100
    - 즉, 데이터를 동일한 비율로 잘라서 비교 가능한 기준을 만들기 위함. 평균이 놓치는 분포의 특성을 더 잘 파악할 수 있음.
    - Quantile라고 부름

- IQR: Inter Quantile Range
    - 중앙값 좌우로 동일한 백분율을 가진 두 점 간의 거리.
    - Outlier에 휘둘리지 않고, 데이터가 어디에 주로 모여 있는지를 알려주는 범위
