## 1. 소개
____

> 교보문고 전자책 DB 구축하기

개발 공부를 시작하면서 개인적으로 만들어보고 싶었던 프로젝트 중 하나가 **전자책 검색 웹서비스** 였다. 전자책 읽는 것이 취미라 예전부터 전자책 검색 웹서비스를 직접 만들어보고 싶었지만, 그동안은 막연하고 어려워 보였다. 하지만 지금은 2주간의 집중할 시간이 주어졌고, 이번엔 꼭 도전해보고 싶다.

- **지난번 시도에서 왜 실패했을까?**
    - 명확한 목표나 일정 없이 시작해서 흐지부지됨
    - 목표가 너무 크고 추상적이었음
    - 스크래핑 전략을 잘못 세워 물리적으로 시간이 너무 오래 걸림
- **다시 도전하는 이유**
    - 오롯이 집중할 수 있는 2주간의 시간이 주어졌음
    - 일단 DB를 구성하는 것을 1차 목표로 삼음. 시작이 반이다.
    - 새로운 병렬 스크래핑 아이디어를 떠올렸고, 이를 직접 적용해보고 싶음
- **이번에 도전하는 내용**
    - 교보문고 전자책 도서관에서 제공하는 전자책 데이터를 스크래핑해 DB 구축
    - 셀레니움 대신 더 빠른 `Playwright` 사용 예정
    - 병렬 스크래핑을 위해 `python Ray` 학습 필요
    - DB 설계와 SQL 공부를 병행해 안정적인 데이터 구조 구성 목표

정확히 어떤 유형이라 단정하기는 어렵다. Python은 익숙하지만 Ray는 처음이고, 주제는 과거에 실패했던 경험이 있는 만큼 이번엔 재도전의 의미가 크다. 우테코 프리코스... 는 잠시 떠나 개인적인 염원을 이루고자 진행하는 과제에 가깝다.
